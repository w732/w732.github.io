About QuickFIX Log Viewer (Web Edition)

QuickFIX Log Viewer

Web & Cloud Edition v2.0

A modern web-based diagnostic tool for analyzing, filtering, inspecting, and troubleshooting FIX (Financial Information eXchange) protocol log files.

Key Capabilities:
  • High performance streaming parser supporting massive log files (100k+ messages).
  • Interactive Virtual Grid, Hierarchical Tree, Field Grid, and Raw FIX view.
  • Multi-session log tabs with real-time live tracing.
  • 16 FIX message category filters, Admin/App filters, and advanced multi-operator custom rules.
  • Interactive Sequence Flow timeline diagram between counterparties.
  • Checksum (modulo 256), body length, and sequence gap health validation.
  • Exporting to FIX, CSV, QuickFIX XML, and JSON.
  • QuickFIX XML data dictionary parser + built-in standard definitions (FIX 4.0 - 5.0SP2).
